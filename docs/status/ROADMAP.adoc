== Current Status

Phase `incubating`, maturity `experimental` (the deed's values; this file does
not change them).

Lintel is a privacy lattice for oblivious DNS, proved in Agda over
`hyperpolymath/secret-types`. As of 2026-11-16:

* The PROVEN claims L-1 to L-4, L-6 and L-7 are Agda-proved under the canonical
  `--safe --without-K --cubical-compatible` invocation (PR #22), and
  re-proved by hand in Rocq and in Lean (PR #23). L-5 is a set of checked
  refusals (`tested-only`); A-1 is an argued assumption. Neither is graded.
* *Grade.* The claims are at `PWG-2ii` as derived by Lintel's own
  `scripts/grade-receipt.sh`, and no higher. That derivation is local to this
  repository.
* *The canon reader refuses the receipt.* The canon reader in
  `metadatastician/standards`
  (`1-formats/deed/tools/deed_lint.js --proof-receipt-json`) currently rejects
  `verification/receipts/agda-pwg_praxis.deed`: it is not in the PROOF-POLICY
  §8.5.1 shape. So the `PWG-2ii` grade has not been confirmed by the canon
  tooling, and the §8.5.1 receipt is an open item (below).
* *`Agda proofs` on `main`.* It has been red since #23 merged (run 42740256887;
  `grade-receipt.sh --check` fails on a stale receipt). Draft PR #27 addresses
  this.

=== M3 — Repository identity completed (owner decisions)

The deed still carries `UNASSIGNED` for fields only the owner can set:
`(ecosystem)` `:position-type`, `:pipeline-position`, `:chain`, and an empty
`:not` (the IS-NOT); the `(anchor)` identity `:kind` and `:domain`; and the
`unique-strength` `:description`. Registration in `gv-clade-index` is the
owner's act. None is filled in here, since none can be proved from the
repository.

=== Not planned / by design

* A-1 (non-collusion) stays an assumption. Confinement of the link is per
  role, and a proxy–target coalition can join the two fields outside any
  program. `Lintel.Instance.collusion-gap` proves the gap.
* The template skeletons under `verification/proofs/{agda,coq,lean4,idris2,tlaplus}`
  prove nothing about Lintel.
