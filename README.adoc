A privacy lattice for oblivious DNS (formerly oDNS), proved in Agda: per-field reader-set labels under which self-defeating privacy compositions are refused, built to instantiate secret-types' noninterference theorem.

== What this is

A Lintel label names the oblivious-DNS roles (client, proxy, target) that may
observe a field, and combining fields intersects their readers. The client's
address may reach the proxy and the query name may reach the target, but the
two together are the client's alone. A composition that would show one
non-client role both of them therefore needs a flow the lattice refuses. The
proofs are in Agda (`--safe --without-K`). The noninterference theorem the
lattice is built to instantiate comes from
link:https://github.com/hyperpolymath/secret-types[hyperpolymath/secret-types],
consumed at a pinned commit.

== Repository scaffolding

Lintel was minted from `rsr-template-repo`, which supplies:

* *Machine-readable metadata* (`.machine_readable/descriptiles/`) — `STATE`, `META`,
  `ECOSYSTEM`, `PLAYBOOK`, `AGENTIC`, `NEUROSYM`, `CLADE`, and `anchors/ANCHOR`,
  in deed, so tools and agents can read the project's state and boundaries.
* *AI gatekeeper protocol* — `lintel_chora.deed` (the repo deed) is the
  universal entry point that tells an AI agent how to work in this repo before it
  touches anything; it carries the AI allocation policy and the ply directory tree.
* *Typed ABI/FFI seam* — `src/interface/Abi/` (Idris2 type + layout proofs) over
  `src/interface/ffi/` (Zig implementation), with generated C headers.
* *CI/CD* — GitHub Actions for quality, security (CodeQL, Scorecard, secret
  scanning), multi-forge mirroring, and RSR anti-pattern enforcement.
* *Supply-chain & reproducibility* — container layering (stapeln), Guix shells,
  SBOM, and signing hooks.
* *Governance* — `GOVERNANCE.adoc`, `MAINTAINERS.adoc`, `.github/` community health
  files, and a release `AUDIT.adoc` gate.

== Repository map

The authoritative map is generated, so it cannot drift from the tree:
link:docs/architecture/REPOSITORY-MAP.adoc[docs/architecture/REPOSITORY-MAP.adoc]
(regenerate with `just repo-map`; CI fails if it is stale).

The short version:

[cols="1,3"]
|===
| Path | What lives there

| `README.adoc`, `CLAUDE.md` | Start here - humans and AI agents respectively.
| `src/`, `tests/`           | The code and its tests.
| `docs/`                    | Human documentation, including the full map above.
| `.machine_readable/`        | Manifests, contractiles and policies that tools read.
| `build/`, `Justfile`       | Every task runs through `just`; phases live in `build/just/`.
| `ci/`, `.github/`          | CI configuration; GitHub reads `.github/` and no other path.
|===
